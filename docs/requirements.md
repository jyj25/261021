# 요구사항 명세

## 문서 정보

| 항목 | 내용 |
| --- | --- |
| 문서 번호 | LAB-SRS-001 |
| 버전 | 2.0 |
| 상태 | 초안 |
| 참고 | ISO/IEC/IEEE 29148 요구사항 구조 참고 |

## 1. 목적과 범위

연구자가 실험 CSV를 공유 작업공간에 게시하고 정리·비교·이상치 탐색·시각화·코드 및 보고서 초안을 만들 수 있는 AI 기반 웹 프로그램이다. 링크를 가진 누구나 저장된 프로젝트 자료를 읽고 수정할 수 있어야 한다. 반드시 원격 호스팅에서 실행하며 로컬 웹 서버는 제공하지 않는다.

## 2. 기능 요구사항

| ID | 요구사항 | 우선순위 | 완료 기준 |
| --- | --- | --- | --- |
| FR-001 | CSV를 공유 작업공간에 게시하고 기존 데이터를 교체한다. | 필수 | 다른 방문자도 게시된 CSV를 확인 |
| FR-002 | 빈 행, 중복 행, 결측값 처리 방식을 선택한다. | 필수 | 처리 설정과 행 수가 표시됨 |
| FR-003 | 실험 조건별 수치 요약과 그룹 그래프를 제공한다. | 필수 | 조건 열 및 측정 열을 선택 가능 |
| FR-004 | IQR 및 Z 점수 기준으로 이상치 후보를 표시한다. | 필수 | 후보 행과 기준 표시, 자동 삭제 금지 |
| FR-005 | 산점도, 선 그래프, 막대, 히스토그램, 상자 그림을 생성한다. | 필수 | 화면에서 그래프 확인 및 HTML 다운로드 |
| FR-006 | 선택된 분석 조건을 재현하는 Python 코드를 생성·편집·공유한다. | 필수 | 코드가 저장되어 다른 방문자에게 보임 |
| FR-007 | 집계값을 바탕으로 결과 해석 초안을 생성한다. | 필수 | API 동의 후 한국어 초안 제공 |
| FR-008 | 분석 보고서를 생성·편집·공유하고 Markdown으로 내려받는다. | 필수 | 공유 보고서가 저장되어 다른 방문자에게 보임 |
| FR-009 | 공유 작업공간에 로그인 없이 쓰기 접근을 허용한다. | 필수 | 공용 Supabase 정책 적용 |

## 3. 품질 및 제약

| ID | 요구사항 |
| --- | --- |
| NFR-001 | 모든 사용은 HTTPS 호스팅에서 수행하며 앱에 localhost 실행 경로를 두지 않는다. |
| NFR-002 | 업로드 제한은 20 MB 및 250,000행이다. |
| NFR-003 | AI에는 원본 행이 아닌 집계값만 보내며 전송 전 동의를 받는다. |
| NFR-004 | AI 결과는 검토 대상 초안으로 표시하고 연구자 확인을 요구한다. |
| NFR-005 | 변경 가능한 공개 작업공간이므로 공개 가능한 데이터만 취급하도록 안내한다. |

## 4. 공개 편집 위험

누구나 CSV와 문서를 덮어쓸 수 있으며 복구 기능은 기본 제공하지 않는다. AI API 키를 연결하면 방문자가 요청을 반복해 운영자의 사용료가 증가할 수 있다. 공개 키에는 비용 한도·사용량 경보를 설정하고 민감 데이터는 게시하지 않는다.
