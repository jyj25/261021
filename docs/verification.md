# 호스팅 검토 체크리스트

이 문서는 배포된 HTTPS 사이트에서 기능과 공개 편집 동작을 확인하기 위한 절차입니다. 로컬 서버를 실행하지 않습니다.

## 사전 조건

- GitHub의 배포 저장소에 `starter` 파일이 올라가 있다.
- Supabase에서 `infra/supabase.sql`을 실행했다.
- Streamlit Community Cloud Secrets에 `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`가 등록되어 있다.
- AI 기능을 점검할 경우에만 `OPENAI_API_KEY`와 비용 한도를 준비한다.
- 아래 과정에는 공개 가능한 테스트용 CSV만 사용한다.

## 수동 점검

| ID | 확인할 동작 | 절차 | 기대 결과 |
| --- | --- | --- | --- |
| V-01 | 첫 방문 | 배포 HTTPS 주소를 연다. | 실험 데이터 분석 화면과 공개 편집 안내가 나타난다. |
| V-02 | 데이터 게시 | 작은 CSV를 올리고 게시한다. | 행과 열이 분석 화면에 표시된다. |
| V-03 | 공동 열람 | 다른 브라우저나 시크릿 창에서 같은 주소를 연다. | 방금 게시한 공유 CSV가 보인다. |
| V-04 | 데이터 정리 | 중복 행 제거와 결측 처리 방식을 선택한다. | 분석 자료와 정리 내역이 설정을 반영한다. |
| V-05 | 조건별 비교 | 조건 열과 숫자형 측정 열을 선택한다. | 그룹별 관측 수, 평균, 표준편차, 중앙값과 분포 그래프가 표시된다. |
| V-06 | 이상치 후보 | IQR과 Z 점수를 각각 선택한다. | 후보 행 수와 행 목록이 표시되고 원자료 행은 자동 삭제되지 않는다. |
| V-07 | 그래프 | 각 그래프 종류와 축을 바꿔 본다. | 선택한 변수와 그래프 종류가 반영된다. |
| V-08 | 코드 수정 공유 | 생성 코드를 수정해 공유 저장 후 다른 브라우저에서 새로고침한다. | 수정한 코드가 다른 브라우저에도 보인다. |
| V-09 | 보고서 수정 공유 | 보고서 문장을 수정해 공유 저장 후 다른 브라우저에서 새로고침한다. | 수정된 보고서 초안이 보이고 Markdown 내려받기가 된다. |
| V-10 | CSV 교체 | 두 번째 공개용 CSV를 게시한다. | 새 자료로 공유 공간이 바뀌고 이전 보고서 초안은 초기화된다. |
| V-11 | AI 초안 | 비용 설정을 확인한 뒤 동의 체크와 생성 버튼을 누른다. | 집계값 기반 해석 초안이 생성되어 공유된다. 원본 행은 AI 요청에 포함되지 않는다. |
