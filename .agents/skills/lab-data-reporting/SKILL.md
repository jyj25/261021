# 실험 데이터 분석 및 보고서 작성

## 목적

CSV 실험 자료를 정리하고 탐색 분석을 수행한 뒤, 근거와 한계를 분리한 재현 가능한 보고서 초안을 만든다. 이 스킬은 프로젝트 앱의 분석 흐름과 보고서 작성 규칙을 재사용한다.

## 분석 흐름

1. 파일명, 인코딩, 행·열 수, 열 이름, 자료형, 단위·결측값·중복 여부를 확인한다. 열 이름만으로 조건이나 측정 의미를 단정하지 않는다.
2. 분석 전에 정리 규칙을 기록한다. 빈 행 제거, 중복 제거, 결측값 유지·행 제거·숫자형 중앙값 대체 중 적용한 내용을 보고서에 표시한다. 원본 데이터는 보존하고 정리된 사본만 계산에 쓴다.
3. 각 숫자형 변수의 관측 수, 평균, 표준편차, 중앙값, 범위와 결측 현황을 요약한다. 표본 수와 단위를 함께 확인한다.
4. 조건별 비교에서는 조건 열과 결과 열을 명시하고 각 그룹의 관측 수와 분포를 보여 준다. 기술 통계의 차이를 유의성 또는 인과관계로 표현하지 않는다. 적절한 검정과 가정이 정해지지 않았다면 검정 결과를 만들지 않는다.
5. 이상치 탐색 방법과 기준을 명시한다. IQR은 기본적으로 1.5배 범위, Z 점수는 절댓값 3 초과를 후보로 표시한다. 후보는 오류로 단정하거나 자동 제거하지 않는다.
6. 그래프 제목, 축, 단위, 그룹 구분을 명확히 하고 표본 수가 큰 경우 시각적 과밀을 설명한다.
7. 분석 코드에는 입력 파일, 정리 기준, 선택한 조건 및 분석 방법을 명시한다. 코드와 수치 요약이 같은 자료·기준을 사용하도록 확인한다.
8. 결과 해석은 관찰한 값과 가능한 설명, 확인이 필요한 가설을 분리한다. 배경 정보가 부족하면 빈칸이나 질문으로 남긴다.
9. 보고서에 다음을 포함한다: 연구 질문 또는 목적, 데이터와 방법, 정리 내역, 결과 표·그래프, 관찰 중심 해석, 제한점, 후속 확인 사항.

## AI 및 데이터 취급

- AI가 실험 원자료를 받는 경우 사전 동의와 승인된 데이터 처리 경로가 필요하다. 이 프로젝트 앱은 외부 AI에 집계 통계만 전달한다.
- 모델이 생성한 해석은 초안이며 연구자가 원자료와 실험 맥락을 대조해야 한다.
- 통계적 유의성, 인과, 메커니즘, 재현성, 안전성은 분석 설계와 근거 없이는 주장하지 않는다.
- 이상치·결측값 처리, 그룹 비교, 단위 변환이 결과를 바꿀 수 있으면 처리 전후를 기록한다.
- 공개 공유 공간에는 공개가 승인된 자료만 둔다.

## 보고서 표현 원칙

- 관찰: "A 조건의 표본 평균은 B보다 높게 관찰되었다."
- 불확실성: "그 차이가 실험 조건 때문인지는 현재 자료만으로 판단하기 어렵다."
- 제한점: "반복 수와 측정 단위가 확인되지 않아 추정의 불확실성을 평가하지 않았다."
- 후속 확인: "실험 반복 구조, 제외 기준, 장비 보정 상태를 확인할 필요가 있다."

보고서에 사용한 분석 조건과 코드를 함께 저장해 다른 연구자가 검토하고 수정할 수 있도록 한다.
